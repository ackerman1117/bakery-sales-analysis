# 数据字典 / Data Dictionary

> 数据模型：**购买记录**是唯一事实表；**商品原料信息**、**日期维度表**是维度表。
> 其余结果全部由代码计算，不从 Excel 读取。

## 1. 表结构总览

### 输入表

| 角色 | Sheet | 必需 | 粒度 |
|---|---|---|---|
| 事实表 | 购买记录 | 是 | 一行 = 一个订单中的一个商品 |
| 维度表 | 商品原料信息 | 是 | 一行 = 商品 × 原料（配方 BOM） |
| 维度表 | 日期维度表 | 是 | 一行 = 一天 |
| 维度表 | 原材料信息 | 否 | 一行 = 原料（价格 / 包装 / 单位） |
| 事实表 | 原料实际消耗 | 否 | 一行 = 日期 × 原料 |

### 输出表

| 结果表 | 粒度 | 主要用途 |
|---|---|---|
| 销售概览 | 整体 | 经营 KPI |
| 单日产品销售量 | 日期 × 商品 | 销量与销售额 |
| 产品偏好 | 商品 | 畅销度、复购、占比 |
| 口味偏好 | 口味 | 甜/咸偏好 |
| 客流量_分时段 | 日期 × 小时 | 分时客流 |
| 客流规律_分星期 | 星期 × 小时 | 排班依据 |
| 小时工排班建议 | 星期 × 小时 | 在岗人数与工时 |
| 节假日效应 | 日期类型 | 节假日经营对比 |
| 原料理论消耗 | 日期 × 原料 | 应消耗量 |
| 原料消耗汇总 | 原料 | 总消耗、成本、实际对比 |
| 原料采购建议 | 月份 × 原料 | 建议采购量与金额 |
| 实际与理论消耗对比 | 日期 × 原料 | 损耗/超耗 |
| 数据校验 | 检查项 | 数据质量 |

## 2. 输入字段定义

### 2.1 购买记录（必需）

| 字段 | 类型 | 说明 |
|---|---|---|
| 时间 | TIME | 下单时刻，用于小时客流 |
| 身份id | INT | 顾客编号；缺失时客流按单号去重 |
| 单号 | TEXT | 订单号，一单可含多行 |
| 产品 | INT | 商品编号（外键 → 商品原料信息.商品编号） |
| 数量 | INT | 购买件数 |
| 消费金额 | DECIMAL(10,2) | 行金额；单价由 金额 ÷ 数量 反推 |
| 日期 | DATE | 交易日期（外键 → 日期维度表.日期） |
| 节假日 | 是/否 | 可选；清洗时以日期维度表为准，原值被覆盖 |

> 建议后续增加：`单价`、`折扣/优惠金额`、`支付方式`、`销售渠道`、`是否退款`。

### 2.2 商品原料信息（必需，配方 BOM）

| 字段 | 类型 | 说明 |
|---|---|---|
| 商品名称 | TEXT | |
| 商品编号 | INT | 商品主键 |
| 口味风格 | INT | 1 = 甜味，2 = 咸味 |
| 原材料 | TEXT | 原料名称；建议增加 `原料编号` 作为外键 |
| 重量 | DECIMAL(8,2) | 单件用量 |
| 单位 | TEXT | 可选（g / kg / ml / L）；缺失时液体原料按 ml、其余按 g |

> 建议后续增加：`原料编号`、`重量单位`（每行必填）、`损耗率`、`配方版本/生效日期`。

### 2.3 日期维度表（必需）

| 字段 | 类型 | 说明 |
|---|---|---|
| 日期 | DATE | 主键 |
| 年 / 月 / 季度 | INT / INT / TEXT | |
| 星期 | TEXT | 一 ~ 日 |
| 是否周末 | 是/否 | |
| 是否节假日 | 是/否 | 法定节假日口径 |
| 日期类型 | TEXT | 工作日 / 周末 / 法定节假日 / 调休上班 |
| 月份文本 | TEXT | 1月 ~ 12月 |
| 节假日名称 | TEXT | 元旦 / 春节 / 国庆节 等 |
| 备注 | TEXT | 调休说明 |

### 2.4 原材料信息（可选）

| 字段 | 类型 | 说明 |
|---|---|---|
| 原料名称 | TEXT | 与 BOM.原材料、原料实际消耗.原料名称 对应 |
| 规格 | TEXT | 包装形式：袋 / 盒 / 桶 / 罐 |
| 数量 | DECIMAL(8,2) | 单个包装的含量（kg 或 L） |
| 单位 | TEXT | KG / L；同时决定 BOM 液体原料的默认单位 |
| 价格 | DECIMAL(8,2) | 按当前约定视为 **元 / KG 或 元 / L** |

接入后才会输出：`单价`、`消耗成本估算`、整包装采购数与预计金额。

> 建议后续增加：`原料编号`（主键）、`计价单位`（元/kg、元/袋）、`安全库存`、`供应商`、`保质期`。

### 2.5 原料实际消耗（可选）

| 字段 | 类型 | 说明 |
|---|---|---|
| 日期 | DATE | |
| 原料名称 | TEXT | |
| 消耗量 | DECIMAL(8,2) | 实际领用量 |
| 单位 | TEXT | 可选；g / ml 会自动换算为 kg / L |

接入后才会输出「实际与理论消耗对比」，并在原料汇总中增加实际值、差异与判定。

## 4. 表间关联

```
日期维度表.日期 ──1:N──> 购买记录.日期
商品原料信息.商品编号 ──1:N──> 购买记录.产品
商品原料信息.原材料 ──N:1──> 原材料信息.原料名称
原材料信息.原料名称 ──1:N──> 原料实际消耗.原料名称
```

## 5. 计算口径与假设

1. **唯一事实来源**：所有经营指标都由购买记录派生；Excel 中已有的结果表被忽略。
2. **客流人次**：同一小时段内按身份id 去重；身份id 为空时退化为单号。
3. **BOM 单位**：优先取 BOM 的 `单位` 列；缺失时液体原料（原材料信息单位为 L/ml）按 ml，其余按 g。
   统一换算为 kg / L，换算系数见 `config.UNIT_FACTORS`。
4. **原料价格**：`原材料信息.价格` 视为元 / KG 或元 / L；若实际是「元/袋」，需先折算成元 / KG。
5. **排班**：默认每人每小时服务 15 人次，小时工资 30 元；参数在 `config.py` 可调。
6. **采购建议**：用历史日均消耗外推，不含季节/节假日加权，期初库存按 0 处理；
   整包采购按包装含量向上取整。
7. **实际 vs 理论**：只在实际录入的「日期 × 原料」上对比；差异率 ±5% 视为正常。
8. **重复明细**：程序不自动删除完全重复的订单行，只在数据校验中标记。

## 6. 已知数据问题与建议

| 问题 | 影响 | 处理 / 建议 |
|---|---|---|
| Excel 自带的结果表口径不一致 | 无法直接复用 | 已全部改为由购买记录重新计算 |
| 样例数据仅 11 个营业日、14 单 | 日均与排班结果波动大 | 仅用于流程验证，真实数据放在 `data/raw/` |
| 购买记录存在 1 行完全重复 | 销量与销售额可能重复计数 | 数据校验中标为「需关注」，确认后在下游或源头去重 |
| BOM 缺少重量单位 | 无法可靠换算 | 建议 BOM 增加 `单位` 列；当前按原料形态推断 |
| 原材料价格计量口径不明 | 成本与采购金额可能偏差 | 建议增加 `计价单位` 字段 |
| BOM、原料实际消耗无原料编号 | 改名后关联易断裂 | 建议增加 `原料编号` 主键 |
| 产品生产、原料采购入库未接入 | 无法做产销匹配和库存结余 | 后续按 README 路线图接入 |
