# 数据字典 / Data Dictionary

## 1. 表结构总览

| 类型 | Sheet | 说明 | 粒度 |
|---|---|---|---|
| 事实表 | 购买记录 | 订单明细 | 一行 = 一个商品行 |
| 事实表 | 产品生产 | 每日生产记录 | 一行 = 商品 x 日期 |
| 事实表 | 原料消耗 | 每日原料消耗 | 一行 = 原料 x 日期 |
| 维度表 | 商品原料信息 | 配方 BOM | 一行 = 商品 x 原料 |
| 维度表 | 原材料信息 | 原料主数据 | 一行 = 原料 |
| 维度表 | 日期维度表 | 2026 全年日历 | 一行 = 一天 |
| 结果表 | 单日产品销售量 | 商品日销量 | 一行 = 商品 x 日期 |
| 结果表 | 原料采购 | 月度采购量 | 一行 = 原料 x 月份 |
| 结果表 | 客流量 | 分时段客流 | 一行 = 时段 x 日期 |
| 结果表 | 口味偏好 | 口味维度汇总 | 一行 = 口味 x 日期类型 |
| 结果表 | 产品偏好 | 产品维度汇总 | 一行 = 产品 |

## 2. 字段定义

### 购买记录
| 字段 | 类型 | 说明 |
|---|---|---|
| 时间 | TIME | 下单时刻 |
| 身份id | INT | 顾客/会员编号 |
| 单号 | TEXT | 订单号，同一单可含多行 |
| 产品 | INT | 商品编号（外键 → 商品原料信息.商品编号） |
| 数量 | INT | 购买件数 |
| 消费金额 | DECIMAL(10,2) | 行金额 = 单价 x 数量 |
| 日期 | DATE | 交易日期（外键 → 日期维度表.日期） |
| 节假日 | BOOL(是/否) | 是否法定节假日 |

## 3. 表间关联

```
日期维度表.日期 ──1:N──> 购买记录.日期 / 单日产品销售量.日期 / 客流量.日期 / 原料消耗.日期
商品原料信息.商品编号 ──1:N──> 购买记录.产品 / 产品生产.商品编号 / 单日产品销售量.商品编号
原材料信息.原料名称 ──1:N──> 商品原料信息.原材料 / 原料消耗.原料名称 / 原料采购.原料名称
日期维度表.月份文本 ──1:N──> 原料采购.日期
```

## 4. 已识别的数据质量问题

| 问题 | 影响 | 处理 |
|---|---|---|
| 原料消耗日期曾为 20261201/202612 混杂数字 | 无法按日聚合 | 已统一为标准日期 |
| 原料采购日期为“1月”文本 | 无法参与日期运算 | 清洗层 `parse_month` 解析月份数字 |
| 产品偏好重复表头“历史销售总额” | 列名冲突 | 已改为“毛利率” |
| 原材料信息缺原料编号主键 | 仅靠名称关联易断裂 | 建议后续补充 |
| 单日产品销售量原缺销售额 | 无法与偏好表口径对齐 | 已新增“销售额”列 |
