# 面包店数据分析 / Bakery Sales Analysis

> 以「购买记录」为唯一事实表，派生销量、客流、偏好、原料消耗与排班/采购建议。

## 数据模型

只把原始经营数据当输入，Excel 里已经算好的结果表一律不再读取：

| 角色 | Sheet | 说明 |
|---|---|---|
| 事实表（必需） | `购买记录` | 订单明细，一行 = 一个商品行 |
| 维度表（必需） | `商品原料信息` | 配方 BOM，商品 × 原料的用量 |
| 维度表（必需） | `日期维度表` | 2026 全年日历，含节假日 / 调休 / 星期 |
| 维度表（可选） | `原材料信息` | 原料价格、包装规格、计量单位；接入后才有成本和整包采购建议 |
| 事实表（可选） | `原料实际消耗` | 实际领用记录；接入后才能做「实际 vs 理论」对比 |

其余 sheet（`原料消耗`、`单日产品销售量`、`原料采购`、`客流量`、`口味偏好`、`产品偏好`、`产品生产` 等）
目前**不参与计算**，程序运行时会在终端列出被忽略的 sheet。

## 数据流

```
购买记录 ─┬─ 单日产品销售量 ─┬─ 产品偏好 / 口味偏好
          │                  └─ 原料理论消耗 ─┬─ 原料消耗汇总
          │                                  └─ 原料采购建议
          ├─ 客流量_分时段 ─ 客流规律_分星期 ─ 小时工排班建议
          └─ 销售概览 / 节假日效应

原料实际消耗（可选） ─ 实际与理论消耗对比
商品原料信息 + 日期维度表 ─ 作为维表参与上述全部计算
```

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python -m src.run_all
```

使用自己的数据：把 Excel 放到 `data/raw/food.xlsx`，再运行 `python -m src.run_all`；
也可指定路径：`python -m src.run_all --data path/to/food.xlsx`。

## 输出结果

| 结果表 | 粒度 | 用途 |
|---|---|---|
| `销售概览` | 整体 | 订单、客流、销量、销售额、客单价 |
| `单日产品销售量` | 日期 × 商品 | 销量、销售额、订单数、购买人次 |
| `产品偏好` | 商品 | 销量/销售额占比、排名、复购率、日均 |
| `口味偏好` | 口味 | 甜/咸销量、销售额与占比 |
| `客流量_分时段` | 日期 × 小时 | 每小时人次、订单数、客单价 |
| `客流规律_分星期` | 星期 × 小时 | 日均客流，用于排班 |
| `小时工排班建议` | 星期 × 小时 | 建议在岗人数、工时、人力成本 |
| `节假日效应` | 日期类型 | 工作日/周末/节假日的日均对比 |
| `原料理论消耗` | 日期 × 原料 | 销量 × BOM 用量 |
| `原料消耗汇总` | 原料 | 总消耗、日均、占比、成本（可选实际对比） |
| `原料采购建议` | 月份 × 原料 | 预计消耗 + 安全库存 → 建议采购量/包装数 |
| `实际与理论消耗对比` | 日期 × 原料 | 实际领用 vs 应消耗，差异率与判定 |
| `数据校验` | 检查项 | 字段缺失、外键、重复、日期覆盖 |

## 关键口径

- **销量 / 销售额**：购买记录中 `数量` / `消费金额` 求和；客单价 = 销售额 ÷ 订单数。
- **消费人次**：同一小时段内按 `身份id` 去重（缺失时退化为 `单号`）。
- **原料理论消耗**：销量 × BOM「重量」，BOM 未写单位时固体按 g、液体按 ml，
  统一换算为 kg / L；`原材料信息.价格` 按「元 / KG 或 元 / L」参与成本估算。
- **排班**：建议在岗人数 = ⌈日均客流人次 ÷ 单人每小时服务能力⌉（默认 15，见 `config.py`）。
- **采购**：建议采购量 = 日均消耗 × 当月天数 + 日均消耗 × 安全库存天数（默认 3 天）；
  若接入 `原材料信息`，再向上取整到整包装并估算金额。
- **实际 vs 理论**：只在实际录入的「日期 × 原料」上做同期对比，避免把部分日期的实际值
  和整段理论值直接相减。

所有参数集中在 [src/config.py](src/config.py)，无需改代码即可调整。
